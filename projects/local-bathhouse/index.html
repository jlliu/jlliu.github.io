Local Bathhouse

A point-and-click game made fully with Risograph prints.

"Local Bathhouse" is a web-based game made entirely with scanned risograph prints. Inspired by risograph animation and point-and-click Flash escape room games, the game allows players to explore a bathhouse–from the lobby, to the locker room, showers, jacuzzi bath, and steam room–and discover surprises along the way.

The project is an exploration in pushing the bounds of playful interaction within the limited material constraints of riso printing; each state of the game was printed as a thumbnail on one of sixteen 11x17" prints, scanned, and made interactive and animated using JavaScript.

This project was generously supported by the SVA RisoLab, where I designed and printed the illustrations used for the game as a Spring 2026 Artist in Residence. The final version is still in development. Check back soon!
